# journal

Injects global instructions and recent journal notes as context at session start. Supports env var overrides:

- `LLM_VANILLA=1` -- skip all custom context
- `NO_JOURNAL=1` -- skip journal reading (start fresh, still writes)

## Config

Reads `~/.config/llm/journal.json`, generated by Nix (`modules/home-manager/llm.nix`). This is shared with the OpenCode journal plugin and Claude Code hooks.

## Events

Emits `journal:loaded` with `{ projectName, notes }` after loading notes. Used by the draft-suggestion extension to generate startup suggestions.
