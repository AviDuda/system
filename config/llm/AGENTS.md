# LLM Agent Configuration

Shared config and per-tool customization for Claude Code, OpenCode, and pi.

@docs/llm-agents.md - Design philosophy, knowledge tiers, extension patterns

## Key Paths

| What | Where |
|------|-------|
| Global instructions (all agents) | `config/llm/instructions.md` |
| Shared constants (Nix) | `modules/home-manager/llm-shared.nix` |
| Journal config (runtime) | `~/.config/llm/journal.json` (generated by Nix) |
| Claude Code hooks | `modules/home-manager/llm.nix` |
| OpenCode plugin | `config/llm/opencode-journal-plugin/` |
| Pi extensions | `config/llm/pi/` (has its own AGENTS.md) |
| Shared skills | `config/llm/skills/` |

## Smoke Testing

After changing journal config, instructions, or shared constants, verify all three agents can load:

```bash
pi -p "Confirm you see journal notes. Say the most recent topic."
opencode run "Read your journal notes. Say the most recent topic."
claude -p "Confirm you see journal notes. Say the most recent topic."
```
